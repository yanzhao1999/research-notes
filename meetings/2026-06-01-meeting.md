我目前已经完成了 spectrogram-based CNN 的两节点分类实验。具体来说，我先对每个已经提取好的 LoRa preamble 样本做 STFT，把一维的 complex IQ 信号转换成 spectrogram。因为 LoRa 信号本身是 chirp signal，频率会随时间变化，所以 spectrogram 能够更直观地表示 preamble 的时频结构。然后我将 spectrogram 作为 CNN 的输入，对 node1 和 node2 进行二分类。数据集方面，每个节点有 2000 个 spectrogram samples，其中前 1000 个用于 training 和 validation，后 1000 个用于 test，因此最终测试集一共有 2000 个样本。CNN-only 的测试准确率为 99.95%，test loss 约为 0.0023，confusion matrix 是 [[999, 1], [0, 1000]]，也就是说 2000 个测试样本中只有 1 个被错误分类，是一个 node1 样本被误判成 node2。

在此基础上，我进一步复现了论文中的 Hybrid Classifier。这个方法是在 CNN 输出 softmax probability 之后，再加入 CFO 作为物理层约束。CNN 先给出每个设备的概率，然后比较当前测试样本的 CFO 和每个节点的 reference CFO。如果差值超过阈值 lambda，就把对应类别的概率置为 0，最后再从更新后的概率中选择最大值作为最终预测结果。在我的实验中，node1 和 node2 的 reference CFO 分别是 -7.27795 bins 和 -4.5995 bins，二者相差约 2.68 bins，说明 CFO 可以作为辅助特征来区分这两个节点。我分析了 CNN 错误分类的那个样本，它的 CNN 输出中 node1 概率为 0.1852，node2 概率为 0.8148，所以 CNN-only 会误判为 node2。但是它的 CFO 是 -7.2455 bins，距离 node1 reference CFO 只有 0.03245 bins，而距离 node2 reference CFO 是 2.646 bins，因此从 CFO 看它明显更接近 node1。加入 Hybrid Classifier 后，node2 的概率会被置为 0，最终可以把该样本修正为 node1。

另外，我也发现 lambda 阈值的选择会影响 Hybrid Classifier 的结果。如果阈值太小，可能会把正确类别也过滤掉，导致准确率下降；如果阈值太大，两个类别都可能通过 CFO 检查，Hybrid Classifier 就几乎不会改变 CNN 的结果。因此，后续需要进一步分析 CFO distribution，并测试不同 lambda，选择一个更合理的阈值。总体来说，目前 spectrogram-based CNN 已经可以很好地区分两个 LoRa 节点，而 CFO-based Hybrid Classifier 可以作为额外的物理层约束，在 CNN 出现错误时帮助修正预测结果。

J’ai actuellement terminé l’expérience de classification à deux nœuds basée sur le spectrogram-based CNN. Plus précisément, j’ai d’abord appliqué la STFT à chaque échantillon de préambule LoRa déjà extrait, afin de convertir le signal IQ complexe unidimensionnel en spectrogramme. Comme le signal LoRa est un signal de type chirp, sa fréquence varie au cours du temps ; le spectrogramme permet donc de représenter plus clairement la structure temps-fréquence du préambule. Ensuite, j’ai utilisé ces spectrogrammes comme entrée du CNN pour effectuer une classification binaire entre node1 et node2. Concernant le jeu de données, chaque nœud contient 2000 échantillons de spectrogrammes : les 1000 premiers sont utilisés pour l’entraînement et la validation, et les 1000 derniers pour le test. Le jeu de test contient donc au total 2000 échantillons. Le modèle CNN seul obtient une accuracy de 99,95 %, avec une loss d’environ 0,0023. La matrice de confusion est [[999, 1], [0, 1000]], ce qui signifie que parmi les 2000 échantillons de test, un seul échantillon est mal classifié : un échantillon de node1 est prédit comme node2.

À partir de ce résultat, j’ai ensuite reproduit le Hybrid Classifier proposé dans l’article. L’idée est d’ajouter une contrainte physique basée sur le CFO après la sortie softmax du CNN. Le CNN fournit d’abord une probabilité pour chaque classe, puis on compare le CFO de l’échantillon testé avec le CFO de référence de chaque nœud. Si la différence dépasse un seuil \lambda, la probabilité correspondant à cette classe est mise à zéro. Ensuite, la classe ayant la plus grande probabilité après cette correction est choisie comme prédiction finale. Dans mon expérience, les CFO de référence sont de -7,27795 bins pour node1 et -4,5995 bins pour node2, avec une différence d’environ 2,68 bins. Cela montre que le CFO peut être utilisé comme une caractéristique complémentaire pour distinguer les deux nœuds. J’ai analysé l’échantillon mal classifié par le CNN : la sortie softmax était 0,1852 pour node1 et 0,8148 pour node2, donc le CNN seul le classait comme node2. Cependant, son CFO est de -7,2455 bins, très proche du CFO de référence de node1, avec une distance de seulement 0,03245 bins, alors que la distance avec node2 est de 2,646 bins. Ainsi, avec le Hybrid Classifier, la probabilité de node2 est mise à zéro, et l’échantillon peut être corrigé comme node1.

J’ai aussi remarqué que le choix du seuil \lambda influence directement le résultat du Hybrid Classifier. Si le seuil est trop petit, il peut éliminer la bonne classe et donc diminuer l’accuracy. Si le seuil est trop grand, les deux classes peuvent passer le test CFO, et le Hybrid Classifier ne modifie presque pas le résultat du CNN. Il faudra donc analyser plus précisément la distribution du CFO et tester différentes valeurs de \lambda afin de choisir un seuil plus adapté. Globalement, le spectrogram-based CNN permet déjà de bien distinguer les deux nœuds LoRa, et le CFO-based Hybrid Classifier peut servir de contrainte physique supplémentaire pour corriger certaines erreurs de prédiction du CNN.


我还对两个节点的 CFO 随时间变化进行了分析，分别做了两组实验：一组是 2 天实验，每 1 分钟记录一次 CFO；另一组是 2 小时实验，每 1 秒记录一次 CFO。从目前结果来看，两个节点的 CFO 分布是明显分开的。在 2 天实验中，node1 的 CFO 大约稳定在 -6.59 bins 附近，node2 的 CFO 大约稳定在 -4.15 bins 附近；在 2 小时实验中，node1 的 CFO 大约在 -6.82 bins 附近，node2 的 CFO 大约在 -4.34 bins 附近。

J’ai également analysé l’évolution du CFO dans le temps pour les deux nœuds, avec deux séries d’expériences. La première expérience dure 2 jours, avec une mesure du CFO toutes les minutes ; la deuxième dure 2 heures, avec une mesure du CFO toutes les secondes. D’après les résultats actuels, les distributions du CFO des deux nœuds sont clairement séparées. Dans l’expérience de 2 jours, le CFO de node1 est relativement stable autour de -6,59 bins, tandis que celui de node2 est autour de -4,15 bins. Dans l’expérience de 2 heures, le CFO de node1 est autour de -6,82 bins, et celui de node2 autour de -4,34 bins.
