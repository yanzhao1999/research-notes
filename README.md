# Research Notes

This repository contains my PhD research notes on LoRa, LoRa RFFI, CNN-based device identification, CFO compensation, and chirp-level signal processing.

## Folder structure

- `daily_log/`: daily research records
- `experiments/`: detailed experimental notes
- `code_notes/`: explanations of important code blocks
- `papers/`: paper reading notes
- `meetings/`: meeting preparation and summaries
- `images/`: figures, plots, confusion matrices, and diagrams
